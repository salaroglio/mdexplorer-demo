# Documenti di gara scaricati

## TL;DR

Qui finiscono i documenti di gara che l'assistente dell'account manager scarica dal portale di Nordica per i bandi
compatibili. Sono la base su cui lavorano i tre responsabili: ciascuno riceve il percorso nell'incarico del giro.

- Un file per bando: `<codice>-capitolato.md`, per esempio `NC-2027-014-capitolato.md`.
- Li scrive il programma `../strumenti/scarica-documento-di-gara.mjs`, con una copia esatta: l'agente decide quale bando,
  il programma copia.
- Entrano nel progetto insieme alla ricerca, quando la persona la approva.
