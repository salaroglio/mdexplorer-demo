# Le schede della gara

## TL;DR

Qui gli agenti scrivono le schede di valutazione del bando: una per responsabile, più la sintesi dell'account manager. All'inizio
la cartella contiene solo questa pagina. Una scheda compare qui dopo che la persona l'ha approvata e scaricata.

- `tecnica.md`, `contrattuale.md` e `delivery.md` le scrivono gli agenti dei tre responsabili.
- `sintesi.md` la scrive l'agente dell'account manager, quando le tre schede sono approvate.
- La cartella esiste già apposta: un agente scrive un file in una cartella che c'è, non ne crea di nuove.

## Chi scrive che cosa

| File | Chi lo scrive | Quando |
|---|---|---|
| `tecnica.md` | `responsabile-tecnico` | dopo l'incarico dell'account manager |
| `contrattuale.md` | `responsabile-legale` | dopo l'incarico dell'account manager |
| `delivery.md` | `responsabile-delivery` | dopo l'incarico dell'account manager |
| `sintesi.md` | `account-manager` | quando le tre schede sono approvate |
