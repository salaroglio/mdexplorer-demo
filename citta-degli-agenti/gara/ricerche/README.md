# Le ricerche dei bandi

## TL;DR

Qui l'agente dell'account manager archivia l'esito di ogni ricerca sul portale del committente: quali procedure ha trovato e quali
meritano il giro dei tre responsabili. Nella posta arriva solo il riassunto; il ragionamento completo sta qui.

- Un file per ricerca, con la data nel nome: `ricerca-AAAA-MM-GG.md`.
- È un primo filtro: giudica la natura del bando e il tempo per rispondere; competenza, tempi e contratto li valutano i responsabili.
- Come ogni documento scritto da un agente, entra nel progetto dopo la tua approvazione.
