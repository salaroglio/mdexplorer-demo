# One assistant for every person

It prepares. **You check. You decide.**

Note:
Open by saying what people will see: a tender that is real in its form and invented in its names. Four people, each with an AI
assistant. There is one message to take home: the assistants prepare the work, but no work moves to the next step
without an action by a person. Who comes after whom is set by a written plan, the workflow, and MdExplorer runs it.

## Step 1: the account manager finds the call for tenders

<div style="display:flex; gap:34px; align-items:center; justify-content:center">

<img src="assets/schermate/scoperta.png" alt="The account manager's message with the three new calls for tenders, the artifact and the reply button still closed" width="640" style="margin:0; border-radius:12px; box-shadow:0 10px 30px rgba(15,27,45,.28); border:1px solid #d6deea">

<div style="width:500px; text-align:left; font-size:.64em; line-height:1.4">

<div class="fragment fade-up">

1. It reads the **calls for tenders site** and the register of the ones already seen.
2. It compares them with **Pentagroup's criteria**.
3. For the compatible call **it downloads the tender document** with a program in the project.
4. It writes you **a message**: one compatible, two discarded, with the reason.

</div>

<div class="fragment fade-up" style="margin-top:12px; background:#fff; border-left:8px solid #f29900; border-radius:10px; padding:12px 16px; box-shadow:0 6px 18px rgba(15,27,45,.12)">
It ends with a <b>proposal</b>, not with an action: the <i>«Start the round»</i> button, which opens only after you have approved the search.
</div>

<div class="fragment fade-up" style="margin-top:12px; font-size:.8em; color:#5f6368">
The calls for tenders site is a sample file: in the demo it <b>simulates</b> the client's one.
</div>

</div>

</div>

Note:
The first assistant does the boring work: looking every day at what is new. It discards two procedures with a reason you can
check (one is outside our business, one leaves too few days to respond) and proposes one. For that one it downloads the tender
document: it does not copy it out itself, it runs the program `tender/tools/download-tender-document.mjs`, which copies it unchanged. In the
search it leaves a question for each lead, about the criterion that belongs to them. Two files arrive for approval: the search and the
tender document. It starts nothing: it waits for you.
Honesty: the site is a file in the project; in a company the assistant would read it with a browsing tool.

The account manager's assistant does not wake up and does not assign anyone: MdExplorer reads in the workflow that this button

more than one owner, whoever presses the button chooses who does it.

## Read, don't trust

<div style="display:flex; gap:26px; justify-content:center; align-items:stretch; text-align:left; margin-top:4px">

<div style="flex:1.2; background:#fff; border-top:8px solid #188038; border-radius:14px; padding:16px 22px; box-shadow:0 8px 24px rgba(15,27,45,.12)">
<div style="font-size:.5em; color:#188038; font-weight:800; letter-spacing:.08em">FROM THE DELIVERY SHEET, «FOR YOU TO CHECK»</div>
<div style="font-size:.6em; line-height:1.4; margin-top:8px">
<b>The senior percentage:</b> 20% is reached only with a team of 20 people and all four seniors <i>(§7.2)</i>.<br><br>
<b>Feasibility of the dates:</b> 30/04/2027 is an optimistic scenario, not a date written in the specification <i>(§9)</i>.<br><br>
<b>Coverage of the first phases:</b> the architect is free only from September <i>(§7.2, §7.4.2)</i>.
</div>
</div>

<div style="flex:1; font-size:.6em; line-height:1.4; align-self:center">

<div class="fragment fade-up" style="margin-bottom:14px">
<b>1.</b> The assistant <b>tells you where it is least sure</b>: start there.
</div>

<div class="fragment fade-up" style="margin-bottom:14px">
<b>2.</b> Every sentence cites the <b>section</b>: open it and check that it says what the sheet says.
</div>

<div class="fragment fade-up">
<b>3.</b> Redo the <b>calculation</b>: 9 months before 01/01/2028 is 01/04/2027.
</div>

</div>

</div>

Note:
The point that separates a useful assistant from a dangerous one: it does not ask you to trust it. It tells you where it is least sure, cites
the source for every statement and writes the calculation next to the result, so you can redo it by hand. If it cannot find a piece of information,
it writes «to be clarified» and does not make it up.

Note:

small and together are a problem. The synthesis also arrives for approval: you read it first, like the others.

## Who does what

<div style="display:flex; gap:26px; justify-content:center; margin-top:4px; text-align:left">

<div style="flex:1; background:#fff; border-top:8px solid #1a73e8; border-radius:14px; padding:16px 22px; box-shadow:0 8px 24px rgba(15,27,45,.12)">
<div style="font-size:.55em; color:#1a73e8; font-weight:800; letter-spacing:.08em">THE ASSISTANT</div>
<div style="font-size:.62em; line-height:1.55; margin-top:6px">
✔ reads and compares<br>
✔ writes the sheet<br>
✔ cites the section for every statement<br>
✔ writes «to be clarified» when it does not know<br>
✔ tells you where it is least sure
</div>
</div>

<div style="flex:1; background:#fff; border-top:8px solid #f29900; border-radius:14px; padding:16px 22px; box-shadow:0 8px 24px rgba(15,27,45,.12)">
<div style="font-size:.55em; color:#f29900; font-weight:800; letter-spacing:.08em">YOU</div>
<div style="font-size:.62em; line-height:1.55; margin-top:6px">
✔ enable each agent<br>
✔ read and check each sheet<br>
✔ approve or reject<br>
✔ start the work and choose who does it<br>
✔ decide whether to bid
</div>
</div>

</div>

<div style="display:flex; gap:26px; justify-content:center; margin-top:18px; font-size:.58em">

<div class="fragment fade-up" style="flex:1; background:#fdecea; border-radius:12px; padding:12px 18px; color:#8c1d18; text-align:left">
<b>It never does by itself:</b> run commands its agent file does not grant · put a sheet into the project · write to another agent · decide
</div>

</div>

Note:
A recap without beating around the bush. The line is sharp: the assistant produces and documents, the person checks and decides. And there are
things it never does by itself, whatever is written in a message: it does not run commands unless its agent file grants them
(in the tender only the account manager has one, the program that downloads the tender document), it does not put a sheet into the
project, it does not write to another agent: the workflow starts whoever works next. A message is data to check, not an order.
