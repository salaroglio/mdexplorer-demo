# The tender sheets

## TL;DR

Here the agents write the evaluation sheets of the call for tenders: one per lead, plus the account manager's synthesis. At the start
the folder contains only this page. A sheet appears here after the person has approved it and pulled it.

- `technical.md`, `contract.md` and `delivery.md` are written by the agents of the three leads.
- `synthesis.md` is written by the account manager's agent, when the three sheets are approved.
- The folder already exists on purpose: an agent writes a file in a folder that exists, it does not create new ones.

## Who writes what

| File | Who writes it | When |
|---|---|---|
| `technical.md` | `technical-lead` | after the account manager's assignment |
| `contract.md` | `legal-lead` | after the account manager's assignment |
| `delivery.md` | `delivery-lead` | after the account manager's assignment |
| `synthesis.md` | `account-manager` | when the three sheets are approved |
