# Pentagroup tender register

## TL;DR

The register keeps track of the calls for tenders Pentagroup has already seen and of what it decided. The account manager's agent
uses it to tell which procedures on the website are new. If a call for tenders is not listed here, it is new.

- A call for tenders enters the register when the account manager has the synthesis of the evaluation.
- Decisions are made by a person, not by the agent.
