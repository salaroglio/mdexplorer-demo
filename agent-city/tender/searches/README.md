# The tender searches

## TL;DR

Here the account manager's agent archives the result of each search on the client's portal: which procedures it found and which
are worth a round of the three leads. Only the summary arrives in the mailbox; the full reasoning is here.

- One file per search, with the date in the name: `search-YYYY-MM-DD.md`.
- It is a first filter: it judges the nature of the call for tenders and the time to respond; competence, timing and contract are assessed by the leads.
- Like every document written by an agent, it enters the project after your approval.
