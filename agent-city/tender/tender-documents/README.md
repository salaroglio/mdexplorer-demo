# Downloaded tender documents

## TL;DR

This is where the tender documents end up that the account manager's assistant downloads from the Nordica portal for the
compatible calls for tenders. They are the basis the three leads work on: each one receives the path in the assignment of the round.

- One file per call for tenders: `<code>-specification.md`, for example `NC-2027-014-specification.md`.
- They are written by the program `../tools/download-tender-document.mjs`, with an exact copy: the agent decides which call for
  tenders, the program copies.
- They enter the project together with the search, when the person approves it.
