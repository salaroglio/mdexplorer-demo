# The MdExplorer demo

A project that shows what MdExplorer does **by using MdExplorer**.

Everything you see is a markdown file inside a git repository.

---

## Where to start

- **ten minutes** — `presentation/`: the idea, in twenty slides
- **half an hour** — `tour/`: eight things to try yourself
- **an hour** — `case-study/`: a project for the AI to work on
- **half an hour more** — `agent-city/`: agents that live in the project

---

## Eight things to try

1. Living documents
2. Diagrams that answer a click
3. MarkAgent, the AI agent
4. Slides written in markdown
5. Word, PDF and site
6. Git without the terminal
7. Rules, skills and MCP
8. Tests in plain language

---

## The case study and the agent city

- **Alpina Servizi** (invented) tries an AI assistant for its help desk: requirements, architecture, plan, minutes.
  The documents hide **three inconsistencies**: ask MarkAgent to find them
- **The agent city**: four people, four agents, a call for tenders. The agents prepare, you decide

---

## When to choose it

- to get to know MdExplorer before using it for real
- to show it to someone
- as a base to start from: **methods** can be added, later too
