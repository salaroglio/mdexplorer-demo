# CHANGELOG

## 1.2.0 — 2026-10-18
- The tender's workflow is now version 3, like the Italian demo: the agent cards say what each piece of work receives, reads and delivers, the account manager's decision is a step of the round («We bid» / «We do not bid»), the roles are ready in `responsibilities.md` and MdExplorer draws the diagram. Before this version the English workflow could not be read and the round did not start. The changed cards ask for trust again.

## 1.1.0 — 2026-10-18
- `.development.yml`: the tender's workflow is in the list `agentCity.workflowDocs`, because a project can have several workflows. It needs an MdExplorer that knows the list; a project with the old `workflowDoc` row sees it converted by itself when it is opened.

## 1.0.0 — 2026-10-18
- First version as a template: the demo project is created from here («Create demo project») and its updates come from here.
