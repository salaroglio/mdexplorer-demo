# La demo come template

Questa cartella fa della demo un **template di progetto** di MdExplorer: `mde-template.yml` dice che cos'è e quale ramo
prendere per ogni lingua, `CHANGELOG.md` che cosa cambia da una versione all'altra.

Un progetto creato dalla demo resta collegato a questo repository: «Scarica gli aggiornamenti» porta le versioni nuove.
